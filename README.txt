beckhamgrasso.com gallery

Upload everything in this folder (index.html, og.jpg and the images folder) to your host
so that index.html sits at the top level.

To add or reorder pieces, open index.html and edit the PIECES list near the bottom.
Each piece needs two files with the same name: images/thumbs/NAME.webp (about 800px wide)
and images/full/NAME.webp (the large version).

images/signature.png is the lettering at the top of the page. images/lineup.png is the
silhouette strip above the footer.

Timelapses live in the videos folder (videos/NAME.mp4, same name as the piece). To add one,
drop the file in that folder (H.264 .mp4, ideally under 1000px and without audio) and add
video: true to that piece's line in the PIECES list.
